# Reposé Residence — scroll-animation design study

A from-scratch, high-fidelity recreation of the interaction design of
`reposeresidence.com`: a 1380vh scrubbed film opening, a chapter break, an
interactive tower/floorplate/residence explorer, a reception walkthrough, a
ten-chapter lifestyle story, an isometric terrace explorer and a closing.

Everything here is original code. No third-party photography, fonts, copy or
compiled bundles are rehosted. Imagery is procedurally generated, fonts are
open-source, and long-form prose is written for this study.

## Run it

Any static server works:

```sh
python3 -m http.server 4173
# open http://localhost:4173
```

There is no build step. `index.html` loads plain CSS and ES modules, with GSAP,
ScrollTrigger and Lenis vendored in `vendor/`.

## Stack

| Piece | Where | Notes |
| --- | --- | --- |
| Smooth scroll | `vendor/lenis.min.js` | `lerp 0.08` desktop / `0.1` touch, `wheelMultiplier 1.15`, driven by the GSAP ticker |
| Animation | `vendor/gsap.min.js`, `vendor/ScrollTrigger.min.js` | pins, scrubs, and the master opening timeline |
| Fonts | `assets/fonts/` | Instrument Serif (display, incl. italic) and Manrope (sans), both SIL OFL — the reference's declared fallback stack |
| Imagery | `assets/**` | generated by `tools/scenes.py` (renderer) + `tools/gen_assets.py` and `tools/gen_floors.py` (numpy + PIL + ffmpeg) |

## The scroll choreography

The opening section is `1380vh` tall with a sticky viewport. One scrubbed
timeline drives everything; time positions are expressed against a
`1280 / 620` scale so the film and the overlays share one clock.

- **Film** — 440 frames (200 approach + 240 ascent) are preloaded progressively
  (critical stride, nearest-first, concurrency 12 desktop / 2–3 coarse) and
  painted to a canvas with a crossfade at the seam (`t 0.408 → 0.512`).
- **Hero** — line masks rise at `t 0.02`, then the copy blurs out by `0.105`.
- **Chapter break** — veil, 92px field grid, five rules, masked lines and a
  sweep across `t 0.408 → 0.512`.
- **Why Dubai / Tallest in Al Furjan** — overlaid cards at `t 0.575 → 0.97`.
- **Residences explorer** — fades in on `--fx-in` from `t 1.04`; becomes
  interactive at `t 1.129`; a scroll gate holds the page at the tower base
  (three attempts, then a skip) until a residence is opened.
- **Reception journey** — a second timeline (`t 1.419 → 1.968`) walks the camera
  to the doors, opens the leaves, blooms through the threshold and settles
  inside.

`js/film.js` holds the frame manifest and mapping, `js/opening.js` the master
timeline, `js/fx.js` the explorer state machine
(`selector → opening → floorplate → switching → openingResidence → residence →
closingResidence → closing`), and `js/rc.js` the camera morph.

## Interactive pieces

- **Floorplate** — 15 generated plates with unit polygons drawn as a
  `viewBox="0 0 100 100"` SVG overlay; hover, keyboard focus, sold hatching,
  wheel-to-change-floor (60px threshold, 520ms cooldown) and pan/zoom
  (wheel zoom anchored at the pointer, drag, double-click toggle, reset).
- **Residence** — unit plan enlargements with a spec sheet.
- **Lifestyle chapters** — a pinned interiors gallery with a FLIP-style cinema
  modal, an amenities index, a horizontal wellness pin
  (`+= innerWidth * 4.2`), a curved sheet reveal, a pinned interiors
  composition, a scrubbed essentials grid, an amenities map, and a finale
  portal pin that morphs into the arrival.
- **Terrace** — an isometric canvas podium with six selectable zones and a
  circular clip transition into detail.
- **Reduced motion** — every scroll animation has a static or short-fade path.

## Generated assets

```sh
python3 tools/gen_assets.py        # film frames, stills, amenities, videos
python3 tools/gen_assets.py seq2   # only re-render the ascent sequence
python3 tools/gen_floors.py        # floorplates + unit plans + js/floor-data.js
```

All imagery is stylised and original. To use real photography, drop files at the
same paths — e.g. `assets/opening/sequence-01/webp/frame-0001.webp`,
`assets/opening/building/final-frame.webp`,
`assets/repose-experience/{pool-01,gym-01,…}.webp` — and the film, stills and
chapters pick them up with no code changes. Fonts can be swapped by replacing
the three `assets/fonts/repose-*.woff2` files.

## Notes on fidelity

The reference is a bespoke production build. This study reproduces its design
system (ink `#090c10` / paper `#f6f4f1`, the `clamp()` type scale, the 0.9/1.05
line heights, 0.12em UI tracking), its DOM and state architecture, and the
timings of its scroll choreography. Imagery, fonts and long copy are
intentionally substitutes, and the terrace uses a canvas 2D scene rather than
the original WebGL model.
